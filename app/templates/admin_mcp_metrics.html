How these are counted

Sign-in
One person's sign-in through an assistant, from consent until it ends (2 hours for a citizen, 8 for an officer). Long-lived program tokens count a new sign-in after 30 minutes without a call.
Completed task
Something the server can see finished: an application filed (an application number returned), an officer decision recorded, or an application's status read. The calls for a task are those since the previous completed task in the same sign-in. A status check counts only in a sign-in that filed or decided nothing.
Repeat and poll
A repeat is the same tool called again with the same inputs, with nothing saved in between. Re-checking the upload link, the number-verification link or the application status after the person replies is asked for by design, so it is a poll, not a repeat.
Wasted call
An error (a tool given input it could not use, or a failure) or a repeat.
Abandoned sign-in
No task completed and no call for 30 minutes.
Privacy
Each call stores only the tool, the outcome, its timing and reply size. The person, the sign-in and the inputs are kept only as one-way keyed codes, used for counting. Kept 30 days.
